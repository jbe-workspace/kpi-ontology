An Aggregation Operator is a type of concept (Genus: skos:Concept) that represents a mathematical or statistical function applied to a set of values to produce a single summary value (Differentia specifica). Genus: Concept (skos:Concept) Differentia specifica: 1. Represents a mathematical/statistical aggregation function 2. Applied to a set of numerical values from instance data 3. Produces exactly one summary output value 4. Is part of the controlled vocabulary <https://semantic.adorsys.com/meta/kpi/AggregationOperatorScheme/1.0> Examples: - kpi:Average - Computes the arithmetic mean - kpi:Sum - Computes the total sum - kpi:Count - Counts the number of values Invariants: - Must be assigned to exactly one skos:ConceptScheme (<https://semantic.adorsys.com/meta/kpi/AggregationOperatorScheme/1.0>) - Must have a skos:notation
Ein Aggregationsoperator ist eine Art von Konzept (Genus: skos:Concept), das eine mathematische oder statistische Funktion repräsentiert, die auf eine Menge von Werten angewendet wird, um einen einzelnen zusammenfassenden Wert zu erzeugen (Differentia specifica). Genus: Konzept (skos:Concept) Differentia specifica: 1. Repräsentiert eine mathematische/statistische Aggregationsfunktion 2. Wird auf eine Menge numerischer Werte aus Instanzdaten angewendet 3. Erzeugt genau einen zusammenfassenden Ausgabewert 4. Ist Teil des kontrollierten Vokabulars <https://semantic.adorsys.com/meta/kpi/AggregationOperatorScheme/1.0> Beispiele: - kpi:Average (Durchschnitt) - Berechnet den arithmetischen Mittelwert - kpi:Sum (Summe) - Berechnet die Gesamtsumme - kpi:Count (Anzahl) - Zählt die Anzahl der Werte Invarianten: - Muss genau einem skos:ConceptScheme zugeordnet sein (<https://semantic.adorsys.com/meta/kpi/AggregationOperatorScheme/1.0>) - Muss eine skos:notation haben

Aggregation Resultc back to ToC or Class ToC

IRI: https://semantic.adorsys.com/meta/kpi/AggregationResult

An Aggregation Result is a type of data record (Genus: owl:Class) that represents the computed numerical value of an aggregation operation for a specific combination of dimension values (Differentia specifica). Genus: Data Record (owl:Class) Differentia specifica: 1. Contains exactly one numerical aggregation value (aggregationValue) 2. Is assigned to a specific combination of dimension values (0..n DimensionValue) 3. Represents one row in the result of an aggregation query 4. The number of DimensionValue assignments corresponds to the number of GranularityDimension instances of the parent KPI Semantics: - Each aggregation result corresponds to one row in the result table of a SPARQL GROUP BY query - The aggregationValue is the result of applying the aggregation operator to the grouped instance data - The DimensionValue instances identify the specific group (row) within the results Examples: - Result: aggregationValue = 3456.78, hasDimensionValue = [gender="M"] - Result: aggregationValue = 2890.12, hasDimensionValue = [gender="W", educationLevel="Abitur"] - Result: aggregationValue = 7894.12, hasDimensionValue = [location="Berlin"] Invariants: - Must have exactly one aggregationValue - The number of DimensionValue instances must match the number of granularity dimensions of the associated KPI
Ein Aggregationsergebnis ist eine Art von Datensatz (Genus: owl:Class), der den berechneten numerischen Wert einer Aggregationsoperation für eine bestimmte Kombination von Dimensionswerten repräsentiert (Differentia specifica). Genus: Datensatz (owl:Class) Differentia specifica: 1. Enthält genau einen numerischen Aggregationswert (aggregationValue) 2. Ist einer bestimmten Kombination von Dimensionswerten zugeordnet (0..n DimensionValue) 3. Repräsentiert eine Zeile im Ergebnis einer Aggregationsabfrage 4. Die Anzahl der DimensionValue-Zuordnungen entspricht der Anzahl der GranularityDimension-Instanzen des übergeordneten KPI Semantik: - Jedes Aggregationsergebnis entspricht einer Zeile in der Ergebnistabelle einer SPARQL-GROUP-BY-Abfrage - Der aggregationValue ist das Ergebnis der Anwendung des Aggregationsoperators auf die gruppierten Instanzdaten - Die DimensionValue-Instanzen identifizieren die spezifische Gruppe (Zeile) innerhalb der Ergebnisse Beispiele: - Ergebnis: aggregationValue = 3456.78, hasDimensionValue = [geschlecht="M"] - Ergebnis: aggregationValue = 2890.12, hasDimensionValue = [geschlecht="W", bildungsniveau="Abitur"] - Ergebnis: aggregationValue = 7894.12, hasDimensionValue = [ort="Berlin"] Invarianten: - Muss genau einen aggregationValue haben - Die Anzahl der DimensionValue-Instanzen muss mit der Anzahl der Granularitätsdimensionen des zugehörigen KPI übereinstimmen

A Dimension Value is a type of value assignment (Genus: owl:Class) that represents the concrete value of a granularity dimension within a specific aggregation result (Differentia specifica). Genus: Value Assignment (owl:Class) Differentia specifica: 1. References exactly one granularity dimension (forDimension) 2. Contains exactly one concrete literal value (dimensionValueLiteral) 3. Is assigned to exactly one aggregation result (via hasDimensionValue) 4. Together with other DimensionValue instances, forms the key of an aggregation result Semantics: - Each dimension value is a cell in a result row - It assigns a concrete value to a granularity dimension - The totality of all dimension values of an aggregation result identifies the group Examples: - DimensionValue: forDimension = [gender], dimensionValueLiteral = "M" - DimensionValue: forDimension = [location], dimensionValueLiteral = "Frankfurt am Main" - DimensionValue: forDimension = [educationLevel], dimensionValueLiteral = "Abitur" Invariants: - Must have exactly one forDimension assignment - Must have exactly one dimensionValueLiteral

Granularity Dimensionc back to ToC or Class ToC

IRI: https://semantic.adorsys.com/meta/kpi/GranularityDimension

A Granularity Dimension is a type of structural element (Genus: owl:Class) that represents a breakdown axis for a key performance indicator and references a property of the reference ontology by which aggregation results are grouped (Differentia specifica). Genus: Structural Element (owl:Class) Differentia specifica: 1. References a property (Data Property or Object Property) of the reference ontology 2. Defines a GROUP BY axis for the aggregation computation 3. Determines the criteria by which aggregation results are broken down 4. Can carry a human-readable label (dimensionLabel) Semantics: - Each granularity dimension represents an attribute by which instance data is grouped - The combination of all dimension values across all granularity dimensions forms the key of an aggregation result - Without granularity dimensions, a single total aggregation value is computed Examples: - Gender: granularityPropertyURI = "http://example.org/hr/ontology/gender" - Location: granularityPropertyURI = "http://example.org/hr/ontology/location" - Education Level: granularityPropertyURI = "http://example.org/hr/ontology/educationLevel" Invariants: - Must have exactly one granularityPropertyURI
Eine Granularitätsdimension ist eine Art von Strukturelement (Genus: owl:Class), das eine Aufschlüsselungsachse für eine Leistungskennzahl repräsentiert und auf eine Eigenschaft der Referenzontologie verweist, nach der die Aggregationsergebnisse gruppiert werden (Differentia specifica). Genus: Strukturelement (owl:Class) Differentia specifica: 1. Referenziert eine Eigenschaft (Data Property oder Object Property) der Referenzontologie 2. Definiert eine GROUP-BY-Achse für die Aggregationsberechnung 3. Bestimmt, nach welchen Kriterien die Aggregationsergebnisse aufgeschlüsselt werden 4. Kann einen menschenlesbaren Bezeichner (dimensionLabel) tragen Semantik: - Jede Granularitätsdimension repräsentiert ein Attribut, nach dem die Instanzdaten gruppiert werden - Die Kombination aller Dimensionswerte über alle Granularitätsdimensionen bildet den Schlüssel eines Aggregationsergebnisses - Ohne Granularitätsdimensionen wird ein einziger Gesamtaggregationswert berechnet Beispiele: - Geschlecht: granularityPropertyURI = "http://example.org/hr/ontology/gender" - Standort: granularityPropertyURI = "http://example.org/hr/ontology/location" - Bildungsniveau: granularityPropertyURI = "http://example.org/hr/ontology/educationLevel" Invarianten: - Muss genau eine granularityPropertyURI haben

Key Performance Indicatorc back to ToC or Class ToC

IRI: https://semantic.adorsys.com/meta/kpi/KeyPerformanceIndicator

A Key Performance Indicator (KPI) is a type of semantic description (Genus: owl:Class) that represents a fully specified aggregation computation over instance data of a reference ontology (Differentia specifica). Genus: Semantic Description (owl:Class) Differentia specifica: 1. References an external ontology whose instance data serves as the data foundation 2. Specifies a property of the reference ontology over which aggregation is performed 3. Uses exactly one aggregation operator from the controlled vocabulary (e.g., AVG, SUM, COUNT) 4. Can be broken down by 0..n granularity dimensions (GROUP BY) 5. Contains 1..n computed aggregation results, each with their dimension values Essential Properties: - referenceOntologyURI: URI of the reference ontology from which data originates - aggregationPropertyURI: URI of the property being aggregated - hasAggregationOperator: The aggregation operator used (exactly one) - hasGranularityDimension: The dimensions by which results are broken down (0..n) - hasAggregationResult: The computed result rows (1..n) - dataSourceURI: Optional URI of the data source (e.g., named graph) - filterExpression: Optional filter expression to restrict instance data Relationships: - To Aggregation Operator: uses exactly one AggregationOperator - To Granularity Dimension: has 0..n GranularityDimension instances - To Aggregation Result: has 1..n AggregationResult instances Examples: - KPI "Average Salary by Gender": referenceOntologyURI = HROntology, aggregationPropertyURI = grossSalary, hasAggregationOperator = Average, hasGranularityDimension = [gender] - KPI "Average Salary by Location": referenceOntologyURI = HROntology, aggregationPropertyURI = grossSalary, hasAggregationOperator = Average, hasGranularityDimension = [location] - KPI "Employee Count by Location": referenceOntologyURI = HROntology, aggregationPropertyURI = location, hasAggregationOperator = Count, hasGranularityDimension = [location] Invariants: - Must have exactly one referenceOntologyURI - Must have at least one aggregationPropertyURI - Must have exactly one hasAggregationOperator - Must have at least one hasAggregationResult
Eine Leistungskennzahl (KPI) ist eine Art von semantischer Beschreibung (Genus: owl:Class), die eine vollständig spezifizierte Aggregationsberechnung über Instanzdaten einer Referenzontologie repräsentiert (Differentia specifica). Genus: Semantische Beschreibung (owl:Class) Differentia specifica: 1. Referenziert eine externe Ontologie, deren Instanzdaten als Datengrundlage dienen 2. Spezifiziert eine Eigenschaft der Referenzontologie, über die aggregiert wird 3. Verwendet genau einen Aggregationsoperator aus dem kontrollierten Vokabular (z.B. AVG, SUM, COUNT) 4. Kann durch 0..n Granularitätsdimensionen aufgeschlüsselt werden (GROUP BY) 5. Enthält 1..n berechnete Aggregationsergebnisse, jeweils mit ihren Dimensionswerten Wesentliche Eigenschaften: - referenceOntologyURI: URI der Referenzontologie, aus der die Daten stammen - aggregationPropertyURI: URI der Eigenschaft, über die aggregiert wird - hasAggregationOperator: Der verwendete Aggregationsoperator (genau einer) - hasGranularityDimension: Die Dimensionen, nach denen aufgeschlüsselt wird (0..n) - hasAggregationResult: Die berechneten Ergebniszeilen (1..n) - dataSourceURI: Optionale URI der Datenquelle (z.B. Named Graph) - filterExpression: Optionaler Filterausdruck zur Einschränkung der Instanzdaten Beziehungen: - Zu Aggregationsoperator: verwendet genau einen AggregationOperator - Zu Granularitätsdimension: hat 0..n GranularityDimension-Instanzen - Zu Aggregationsergebnis: hat 1..n AggregationResult-Instanzen Beispiele: - KPI "Durchschnittsgehalt nach Geschlecht": referenceOntologyURI = HROntology, aggregationPropertyURI = grossSalary, hasAggregationOperator = Average, hasGranularityDimension = [gender] - KPI "Durchschnittsgehalt nach Standort": referenceOntologyURI = HROntology, aggregationPropertyURI = grossSalary, hasAggregationOperator = Average, hasGranularityDimension = [location] - KPI "Anzahl Mitarbeiter nach Standort": referenceOntologyURI = HROntology, aggregationPropertyURI = location, hasAggregationOperator = Count, hasGranularityDimension = [location] Invarianten: - Muss genau eine referenceOntologyURI haben - Muss mindestens eine aggregationPropertyURI haben - Muss genau einen hasAggregationOperator haben - Muss mindestens ein hasAggregationResult haben
